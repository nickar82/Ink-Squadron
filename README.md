# Ink Squadron – Android

Μάχη αεροσκαφών σε τετράδιο με ζάρι και μαρκαδόρο: «Draw your battle. Lead your squadron.»

## Πώς παίζεται
- Ρίχνεις το ζάρι και πατάς ένα από τα όπλα σου. Ο πύραυλός σου (γραμμή μελανιού) μακραίνει κατά τόσα τετράγωνα.
- Όταν η γραμμή φτάσει σε εχθρικό αεροσκάφος, το καταστρέφει. Τα θωρακισμένα θέλουν 2 χτυπήματα και τα boss 2–3.
- **CUT!** Αν η γραμμή σου περάσει μέσα από εχθρική γραμμή στην ίδια στήλη, την σβήνει. Έτσι σταματάς μια βολή που πάει να σε χτυπήσει.
- Οι στήλες που στοχεύουν τη μύτη του εχθρού δεν μπορούν να αμυνθούν. Μετακίνησε σκάφη για να τις βρεις.
- Τα αριθμημένα κυκλάκια δίπλα στα όπλα δείχνουν πόσα τετράγωνα μένουν μέχρι το χτύπημα.
- **Power-ups:**
  - 🚀 Ρουκέτα: +6 αμέσως, χάνεις τη σειρά σου.
  - 🛡 Ασπίδα: μπλοκάρει το επόμενο χτύπημα. Δεν χάνεις τη σειρά σου.
  - ⚡ Κεραυνός: ρίχνεις δύο ζάρια.
  - ↔ Μετακίνηση: το σκάφος πάει ένα τετράγωνο πλάγια, χάνεις τη σειρά σου και σβήνονται οι γραμμές του.
- **OVERDRIVE:** αν περάσουν πολλοί γύροι χωρίς ζημιά, κάθε ζαριά παίρνει +1, +2 κ.ο.κ.

## Λειτουργίες
- **Campaign:** 100 επίπεδα με αυξανόμενη δυσκολία. Από 2 μέχρι 5 σκάφη, εχθροί με περισσότερα σκάφη, θωράκιση, boss κάθε 5 επίπεδα, εξυπνότερο AI, εχθρικά power-ups και από το επίπεδο 35 «Ace pilot». Παίρνεις 1–3 αστέρια ανάλογα με τις απώλειες, και τα αστέρια και η πρόοδος αποθηκεύονται.
- **1 VS 1:** δύο παίκτες στο ίδιο κινητό, πρόσωπο με πρόσωπο, με την οθόνη του Παίκτη 2 ανεστραμμένη. Επιλέγετε 1 έως 5 σκάφη, μήκος πεδίου και αν θα υπάρχουν power-ups.
- **Εφέ:** εκρήξεις, κομμάτια, καπνός, πιτσιλιές μελανιού, κούνημα οθόνης, κομφετί, συνθετικοί ήχοι και δόνηση. Όλα ρυθμίζονται από τα Settings.

## Δομή
```
app/src/main/assets/index.html   ← ολόκληρο το παιχνίδι (HTML5 canvas, χωρίς εξαρτήσεις, offline)
app/src/main/java/.../MainActivity.java ← WebView: fullscreen, κουμπί Back, δόνηση, παύση στο background
app/src/main/res/mipmap-*        ← εικονίδια (και adaptive icon)
store/play_store_icon_512.png    ← εικονίδιο για το Google Play
.github/workflows/build-apk.yml  ← αυτόματο build APK στο GitHub
```

## Πώς βγάζεις APK

### Α) Με Android Studio
1. File → Open → διάλεξε τον φάκελο `InkSquadron`.
2. Περίμενε το Gradle sync. Την πρώτη φορά κατεβάζει το Android SDK 35, αν δεν το έχεις.
3. Build → Build App Bundle(s) / APK(s) → Build APK(s). Το αρχείο βγαίνει στο `app/build/outputs/apk/debug/app-debug.apk`.
4. Για να παίξεις, σύνδεσε το κινητό με USB debugging και πάτα ▶ Run.

### Β) Χωρίς Android Studio, μέσω GitHub
1. Ανέβασε τον φάκελο σε ένα GitHub repository, στο branch `main`.
2. Το workflow **Build Ink Squadron APK** τρέχει αυτόματα. Από την καρτέλα Actions κατεβάζεις το artifact `InkSquadron-debug-apk`.
3. Αντέγραψε το APK στο κινητό και κάνε εγκατάσταση. Θα χρειαστεί να επιτρέψεις την «εγκατάσταση από άγνωστες πηγές».

### Γ) Γραμμή εντολών
```
./gradlew assembleDebug
```
Χρειάζεσαι JDK 17 και το Android SDK, με τη μεταβλητή ANDROID_HOME ρυθμισμένη.

## Για Google Play (release)
1. Φτιάξε keystore με `keytool -genkey -v -keystore release.jks -alias ink -keyalg RSA -keysize 2048 -validity 10000`.
2. Στο GitHub πρόσθεσε τα secrets `KEYSTORE_BASE64` (το αποτέλεσμα του `base64 -w0 release.jks`), `KEYSTORE_PASSWORD`, `KEY_ALIAS` και `KEY_PASSWORD`.
3. Το workflow θα βγάλει υπογεγραμμένο `.aab` για το Play Console και `.apk`.
4. Κράτα το keystore σε ασφαλές μέρος. Χωρίς αυτό δεν μπορείς να βγάλεις ενημερώσεις.

Το package name είναι `com.inksquadron.game` και αλλάζει στο `app/build.gradle` (applicationId).

## Αλλαγές στο παιχνίδι
Όλο το παιχνίδι είναι το `app/src/main/assets/index.html`. Το ανοίγεις σε browser για γρήγορες δοκιμές και κάνεις ξανά build.
